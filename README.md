# Simple Interest Calculator

A lightweight application designed to quickly compute simple interest earnings and total future value based on principal investment amount, annual interest rate, and time duration.

## Formula Used
The application calculates financial growth using the standard simple interest formula:

$$A = P(1 + rt)$$

Where:
* **A** = Total Accrued Amount (Principal + Interest)
* **P** = Principal Amount (Initial Investment)
* **r** = Annual Interest Rate (as a decimal)
* **t** = Time Period (in years)

## Features
* **Instant Calculation**: Computes simple interest instantly upon user input.
* **Breakdown Summary**: Displays both the net interest earned and the final total balance.
* **Input Validation**: Prevents negative values or invalid text formats to maintain data integrity.

## Getting Started
1. Clone this repository to your local machine.
2. Open the main file (`index.html`, `main.py`, or equivalent project file) in your preferred environment.
3. Input your desired principal, rate, and time duration to calculate your returns.
